**ChatGPT** är OpenAI:s AI-assistent. **Microsoft Copilot** är ett namn Microsoft använder för flera AI-upplevelser, bland annat den fristående Copilot-tjänsten och **Microsoft 365 Copilot** i arbetsmiljöer. Därför är det viktigt att skilja mellan vanlig Copilot och de Microsoft 365-funktioner som arbetar med organisationsdata.

De två tjänsterna överlappar inom frågor, webbsökning, textarbete och filanalys, men deras ekosystem och datakopplingar skiljer sig.

## Jämförelse av dokumenterade funktioner

| Funktion | ChatGPT | Microsoft Copilot / Microsoft 365 Copilot |
| :--- | :--- | :--- |
| **Leverantör** | OpenAI | Microsoft |
| **Webbsökning** | Inbyggd webbsökning i ChatGPT | Webbsökning finns i Copilot-upplevelser där den är aktiverad |
| **Filer och dokument** | Filuppladdning och dataanalys | Fil- och dokumentarbete, med djup Microsoft 365-integration i Microsoft 365 Copilot |
| **Arbetsdata** | Kan använda anslutna appar och filer där användaren har gett åtkomst | Microsoft 365 Copilot kan arbeta med behörig data i bland annat Word, Excel, PowerPoint, Teams och Microsoft Graph |
| **AI-modeller** | OpenAI:s aktuella ChatGPT-modeller | Microsoft kan använda flera modellleverantörer och modelltyper beroende på Copilot-upplevelse |
| **Anpassade arbetsflöden** | Plugins, anslutna appar och andra ChatGPT-verktyg beroende på plan | Copilot Studio och Microsoft 365-funktioner för organisationer |

## Microsoft Copilot använder inte bara en modell

Det är missvisande att beskriva Microsoft Copilot som enbart ett skal ovanpå en enda OpenAI-modell.

Microsofts aktuella dokumentation anger att Copilot kan använda flera typer av modeller, bland annat:

- GPT-modeller som drivs av Microsoft via Azure OpenAI,
- GPT-modeller som tillhandahålls av OpenAI,
- Claude-modeller från Anthropic,
- andra modeller som Microsoft kan driva i sin egen infrastruktur.

Vilken modell som används kan bero på produkt, kundtyp, administratörsinställningar och funktion.

## Där ChatGPT skiljer sig

ChatGPT är byggt som en fristående OpenAI-produkt. Beroende på plan kan tjänsten ge tillgång till olika OpenAI-modeller, webbsökning, filanalys, röst, bildfunktioner och anslutna appar.

För privat användning innebär det ofta att du arbetar direkt i ChatGPT och väljer vilka filer eller tjänster du vill koppla in.

## Där Microsoft 365 Copilot skiljer sig

Microsoft 365 Copilot är särskilt utformat för organisationer som redan arbetar i Microsoft 365.

Med rätt licens och behörigheter kan Copilot arbeta i sammanhang som:

- Word-dokument,
- Excel-arbetsböcker,
- PowerPoint,
- Outlook,
- Teams,
- OneDrive och SharePoint,
- annan Microsoft Graph-data som användaren redan har behörighet till.

Det betyder inte att Copilot automatiskt får tillgång till allt i en organisation. Microsofts behörighetsmodell och administratörsinställningar avgör vilken data som får användas.

## Vilken passar ditt användningssätt?

Det finns ingen generell vinnare. Jämför i stället de funktioner du faktiskt behöver.

- Om ditt arbete är tätt kopplat till **Microsoft 365 och organisationsdata**, kontrollera vad Microsoft 365 Copilot kan göra i just din licens och arbetsyta.
- Om du vill ha en **fristående AI-assistent med OpenAI:s ChatGPT-funktioner**, jämför ChatGPT-planernas aktuella modell- och verktygsåtkomst.
- Om webbsökning eller filanalys är viktigast bör du kontrollera aktuella gränser och funktioner i den plan du överväger, eftersom de ändras över tid.
